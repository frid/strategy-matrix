# 策略矩陣分析工具 Strategic Matrix Analyzer

> 「策略矩陣」（Strategic Matrix）是由政大管理學大師司徒達賢教授提出的分析工具，
> 主要用於將企業複雜的競爭策略轉化為直觀、結構化的視覺地圖。

🔗 **線上使用：** [https://jack0630.github.io/strategy-matrix/](https://jack0630.github.io/strategy-matrix/)

📖 **操作手冊：** [manual.html](manual.html)（頁面右上角也有「📖 操作手冊」連結）

---

## ✨ 功能介紹

### 🔗 價值鏈編輯器
- 以價值鏈（Porter 架構）定義分析的欄位：**支援活動**在上（橫跨全寬）、**主要活動**與**產品**在下
- 可建立**群組方塊**並以**連線**標示活動之間的關係（🔗 連線模式：點第一個方塊 → 再點第二個方塊）
- 點名稱可直接改名，支援**拖曳排序**；拖到群組空白處即放進該群組
- 點「活動／資產」可切換單元性質（資產會以不同樣式顯示，例如「品牌／商譽」）
- 「大箭頭背景」可開關價值鏈圖的底色箭頭
- 產品在價值鏈圖外的**產品管理面板**中新增、改名、刪除與拖曳排序
- **📋 載入範本**：內建生醫、其他產業與理論骨架三組範本（例：醫療器材製造、藥廠在台銷售、連鎖藥局、連鎖醫美診所、工業電腦、原物料製造、通用基本價值鏈等）；載入會取代目前價值鏈
- **💾 存價值鏈／📂 載價值鏈**：只匯出／匯入價值鏈本身，不影響矩陣箭頭與策略內容
- **📐 展開到策略矩陣**：依目前價值鏈重新產生下方矩陣的欄位；既有箭頭會依欄位名稱搬移，找不到對應欄位的箭頭會在確認視窗中列出後再刪除

### 🎨 策略矩陣繪製
- 點選格子畫箭頭，自由描繪策略在各價值活動的定位與走向
- 支援最多 **8 個策略**（競爭者），每個策略使用不同顏色區分
- 箭頭可刪除，支援復原（最多 80 步）
- **策略要素標記**：每條箭頭可從 51 項策略要素（《策略管理新論》Ch9）中勾選標記，並依箭頭形狀自動列出建議要素
- **📝 策略句型產生器**：依箭頭自動組成策略句（匯流句、鏈式句），可複製或填入策略說明，PPTX 步驟頁與總覽頁也會附上
- 矩陣欄位採**多層表頭**：依價值鏈的群組自動合併表頭（群組橫向合併，欄名向下延伸）

### 🏭 策略矩陣／產業矩陣切換
一鍵切換矩陣最左欄的標籤內容（按鈕顯示目前模式）：
- **策略矩陣**（預設）：產品、市場、垂直、規模、地理、競優
- **策略矩陣＋產業矩陣**：關聯、市場、垂直、規模、地理、KSF's

### 🗂️ 專案
頁面上方「專案」區（捲動時固定在頁面上方）提供整體專案的操作：

| 按鈕 | 說明 |
|------|------|
| 💾 存檔 | 把整份策略（價值鏈、矩陣、箭頭、策略名稱與說明、配色）匯出成 JSON 檔 |
| 📂 載入 | 載入先前存的 JSON 檔，還原整份內容 |
| 📊 匯出 PPTX | 直接產生 PowerPoint（見下方「匯出格式」） |
| 📚 載入範例 | 載入內建完整範例（網路書店 A 公司、晶圓代工 T 公司，依 Ch9 案例改寫）；會先確認再取代目前內容 |
| 🎨 配色 | 下拉選單切換價值鏈與策略矩陣的配色，內建 6 組：價值鏈同調（藍橘）（預設）、標準規範（黃藍）、冷色簡約、高對比黑白、莫蘭迪柔和、森林大地 |
| 🔄 重設 | 清除瀏覽器中的所有存檔並回到預設值（無法復原，會重新整理頁面） |

### 📤 匯出格式
| 格式 | 說明 |
|------|------|
| 📊 匯出 PPTX | 直接產生 PowerPoint：第一頁為價值鏈圖（有價值鏈時）；之後每個步驟頁下方顯示該箭頭自己的補充說明；最後一頁為完整總覽投影片（顯示策略名稱與說明）。價值鏈與矩陣都是可點選編輯的原生物件，配色跟著目前的配色設定 |

## 🚀 使用方式

### 基本操作
1. **填入策略名稱與說明**（選填）
2. **建立價值鏈**：可直接用預設價值鏈，或按「📋 載入範本」從生醫／其他產業／理論骨架中挑一個起點，再依需要編輯（改名、拖曳、群組、連線、增刪產品）
3. **按「📐 展開到策略矩陣」**，產生矩陣欄位（每次修改價值鏈後都要重新展開，矩陣才會更新）
4. **設定策略名稱**：在「策略構想」區新增策略（最多 8 個），點擊 chip 上的名稱可直接改名
5. **切換到繪製模式**，點第一格（起點）→ 點第二格（終點）→ 自動畫出箭頭
6. 重複步驟 5，繪製完整策略路徑

### 匯出動畫 PPT
1. 選擇要匯出的策略（點選對應 chip）
2. 點「📊 匯出 PPTX」
3. 自動產生逐步揭露的投影片（價值鏈頁在最前面），最後一頁為完整策略圖
4. 在 PowerPoint 中按 F5 播放即可

## 📐 矩陣結構

矩陣的欄位**不再固定**，而是由「價值鏈」的葉節點展開產生，欄位順序為：

| 順序 | 欄位來源 | 說明 |
|------|----------|------|
| 1 | 支援活動 | 價值鏈最上方的支援活動（人力資源、資訊系統、財務管理等，可自訂） |
| 2 | 主要活動 | 價值鏈中的主要活動；若有群組，表頭會顯示群組名稱（多層表頭） |
| 3 | 產品 | 產品管理面板中的產品（產品不分組，排在最後） |

列（策略維度）固定為六個：

| 維度 | 說明 |
|------|------|
| **列（策略維度）** | A 產品線廣度與特色、B 目標市場區隔與選擇、C 垂直整合程度之取決、D 相對規模與規模經濟、E 地理涵蓋範圍、F 競爭優勢 |

## 🛠️ 技術說明

- 純前端單頁應用（Single HTML File）
- 無需後端、無需安裝，直接用瀏覽器開啟即可使用
- 使用技術：HTML / CSS / JavaScript、SVG、html2canvas、JSZip
- 支援瀏覽器：Chrome、Edge、Safari、Firefox（建議使用 Chrome）
- 內容自動暫存於瀏覽器（localStorage），重新整理後仍會保留；要長期保存請用「💾 存檔」
