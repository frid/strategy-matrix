# 策略矩陣分析工具 Strategic Matrix Analyzer

> 「策略矩陣」（Strategic Matrix）是由政大管理學大師司徒達賢教授提出的分析工具，
> 主要用於將企業複雜的競爭策略轉化為直觀、結構化的視覺地圖。

🔗 **線上使用：** [https://jack0630.github.io/strategy-matrix/](https://jack0630.github.io/strategy-matrix/)

📖 **操作手冊：** [manual.html](manual.html)（頁面右上角也有「📖 操作手冊」連結）

---

## ✨ 功能介紹

工具依《策略管理新論》的分析流程，把頁面拆成**六個步驟 tab**：① 經營流程 → ② 策略點描述 → ③ 策略構想 → ④ 前提驗證 → ⑤ 行動計畫 → ⑥ 策略控制。手冊 [manual.html](manual.html) 也依這六步分章。

### 🧭 分步引導與教材說明卡
- **tab 列**：「專案」列下方六個 tab，每格顯示該步完成度（百分比、進度條、一行摘要），右下為整體百分比；完成的步驟打勾；窄螢幕排成 3×2
- **共用矩陣**：② 到 ⑥ 共用同一張策略矩陣（① 只編價值鏈、不顯示矩陣）；切 tab 自動切模式：② 描述策略點、③ 繪製箭頭、④⑤⑥ 檢視
- **教材說明卡**：每個 tab 第一塊，左欄寫這一步的目的、短引文與頁碼，右欄「在這裡做什麼」「完成檢查點」；底部「📖 手冊」連到手冊對應章節，另有「上一步／下一步」；可收合並記住
- **`#step-N` 直連**：網址加 `#step-1`～`#step-6` 直接開到該 tab（例：`index.html#step-4`），切 tab 時網址同步更新；目前 tab 也會寫進存檔

### ① 經營流程
以價值鏈定義矩陣的欄位：**支援活動**在上、**主要活動**與**產品**在下，畫完按「📐 展開到策略矩陣」產生欄位。
- 可建立**群組方塊**，點名稱改名、**拖曳排序**；「活動／資產」切換單元性質；**價值單元角色**（半成品／主導／影響者）會帶到表頭與 PPTX
- **🔗 連線模式**標示活動之間的關係，走線自動避開方塊；「大箭頭背景」可開關
- **📋 載入範本**：生醫、其他產業與理論骨架三組（例：醫療器材製造、藥廠在台銷售、連鎖藥局、連鎖醫美診所、工業電腦、原物料製造、通用基本價值鏈、半成品外售、仲介型、多重產業共用市場）；**💾 存價值鏈／📂 載價值鏈**只存取價值鏈本身
- **📐 展開到策略矩陣**：既有箭頭依欄位名稱搬移，找不到對應欄位的箭頭會在確認視窗列出後再刪除；矩陣採**多層表頭**（群組橫向合併）

### ② 策略點描述
矩陣每一格是一個策略點，這一步逐格掌握現況。
- **📝 描述策略點**：點格子在矩陣下方面板看定義與引導問題並填寫描述；C 列可標 ○自製／✕外包／◐局部整合，F 列可選優勢基礎；顯示填寫進度
- **✂ 短版矩陣**：只顯示跟產品特色有關的欄位；可自動隱藏無箭頭欄、表頭 ✕ 個別隱藏、chip 列叫回；格子代號不變

### ③ 策略構想
用箭頭表達策略要素之間的因果，再把相關箭頭組成模組。
- 點選起點格、終點格畫箭頭；最多 **8 個策略構想**，各用不同顏色；箭頭可寫補充說明、拖曳排序、刪除，支援復原（最多 80 步）
- **構想分型**：〔本〕現行／〔未〕未來方向／〔競〕競爭者（虛線）；👁 檢視切換（只看目前／目前＋競爭者／全部構想），含雙方時以 ⚔ 標出對陣點
- **策略模組**：把箭頭圈成有名字的模組，可套用書上五個模組；**策略要素標記**：51 項要素（Ch9）並依箭頭形狀建議
- **📝 策略句型產生器**：依箭頭自動組成匯流句、鏈式句，可複製或填入策略說明

### ④ 前提驗證
有了具體方案才談 SWOT：檢查每條箭頭背後的前提是否成立。
- 箭頭可加前提（類型、內容、成立度），自動彙整成 S／W／O／T 四象限、待驗證與因果清單，可複製
- **⚔ 對陣點**：本公司與競爭者用到同一策略點的格子，逐點判斷「可強化／須轉移」並寫理由

### ⑤ 行動計畫
把選定的策略構想拆回可執行的行動。
- 從箭頭產生行動項目、指定負責單元、部門與期程、狀態；可依負責單元分組，自動標示跨部門協調；可複製

### ⑥ 策略控制
- **前提控制表**：標記關鍵前提、觀察指標、燈號與下次檢視日（逾期紅字），可複製或匯出 CSV

### 🏭 策略矩陣／產業矩陣切換
一鍵切換矩陣最左欄的標籤內容（按鈕顯示目前模式）：
- **策略矩陣**（預設）：產品、市場、垂直、規模、地理、競優
- **策略矩陣＋產業矩陣**：關聯、市場、垂直、規模、地理、KSF's

### 🗂️ 專案
頁面上方「專案」區（捲動時固定在頁面上方）提供整體專案的操作：

| 按鈕 | 說明 |
|------|------|
| 💾 存檔 | 把整份策略（價值鏈、矩陣、箭頭、策略名稱與說明、配色）匯出成 JSON 檔 |
| 📂 載入 | 載入先前存的 JSON 檔，還原整份內容 |
| 📊 匯出 PPTX | 直接產生 PowerPoint（見下方「匯出格式」） |
| 📚 載入範例 | 載入內建完整範例（網路書店 A 公司、晶圓代工 T 公司，依 Ch9 案例改寫），已含價值鏈、箭頭、策略點描述、策略模組、前提（含關鍵前提）、行動計畫與競爭者構想；會先確認再取代目前內容 |
| 🎨 配色 | 下拉選單切換價值鏈與策略矩陣的配色，內建 6 組：價值鏈同調（藍橘）（預設）、標準規範（黃藍）、冷色簡約、高對比黑白、莫蘭迪柔和、森林大地 |
| 🔄 重設 | 清除瀏覽器中的所有存檔並回到預設值（無法復原，會重新整理頁面） |

### 📤 匯出格式
| 格式 | 說明 |
|------|------|
| 📊 匯出 PPTX | 直接產生 PowerPoint：第一頁為價值鏈圖（有價值鏈時）；之後每個步驟頁下方顯示該箭頭自己的補充說明；最後一頁為完整總覽投影片（顯示策略名稱與說明）。總覽頁後依序接策略點描述、策略模組、前提／SWOT、對陣點、行動計畫、前提控制各頁（沒有資料的頁會跳過並在狀態列提示）；短版矩陣開啟時只畫可見欄。價值鏈與矩陣都是可點選編輯的原生物件，配色跟著目前的配色設定 |

## 🚀 使用方式

### 基本操作（照六個 tab 走）
1. **① 經營流程**：填入策略名稱與說明（選填）；用預設價值鏈，或按「📋 載入範本」挑一個起點再編輯（改名、拖曳、群組、連線、增刪產品）；按「📐 展開到策略矩陣」產生矩陣欄位（每次修改價值鏈後都要重新展開）
2. **② 策略點描述**：自動切到描述模式，點格子在下方面板填寫各策略點的現況
3. **③ 策略構想**：在「策略構想」區新增策略（最多 8 個）並設〔本〕〔未〕〔競〕；點第一格（起點）→ 點第二格（終點）畫出箭頭；替箭頭寫補充說明、標要素、圈成模組
4. **④ 前提驗證**：在 ③ 的箭頭上加前提並標成立度，到 ④ 看 SWOT 彙整與對陣點
5. **⑤ 行動計畫**：按「✨ 從箭頭產生行動項目」，補負責單元與期程
6. **⑥ 策略控制**：勾關鍵前提，填觀察指標、燈號與下次檢視日

每個 tab 頂端的教材說明卡會提示這一步的目的與檢查點；用「下一步 ›」或點 tab 前進。網址加 `#step-N` 可直接開到第 N 步。

### 匯出動畫 PPT
1. 選擇要匯出的策略（點選對應 chip）
2. 點「📊 匯出 PPTX」
3. 自動產生逐步揭露的投影片（價值鏈頁在最前面），之後為完整策略圖，再接策略點描述、模組、SWOT、對陣點、行動計畫、前提控制各頁
4. 在 PowerPoint 中按 F5 播放即可

## 📐 矩陣結構

矩陣的欄位**不再固定**，而是由「價值鏈」的葉節點展開產生，欄位順序為：

| 順序 | 欄位來源 | 說明 |
|------|----------|------|
| 1 | 支援活動 | 價值鏈最上方的支援活動（人力資源、資訊系統、財務管理等，可自訂） |
| 2 | 主要活動 | 價值鏈中的主要活動；若有群組，表頭會顯示群組名稱（多層表頭） |
| 3 | 產品 | 產品管理面板中的產品（產品不分組，排在最後） |

列（策略維度）固定為六個：

| 維度 | 說明 |
|------|------|
| **列（策略維度）** | A 產品線廣度與特色、B 目標市場區隔與選擇、C 垂直整合程度之取決、D 相對規模與規模經濟、E 地理涵蓋範圍、F 競爭優勢 |

## 🛠️ 技術說明

- 純前端單頁應用（Single HTML File）
- 無需後端、無需安裝，直接用瀏覽器開啟即可使用
- 使用技術：HTML / CSS / JavaScript、SVG、html2canvas、JSZip
- 支援瀏覽器：Chrome、Edge、Safari、Firefox（建議使用 Chrome）
- 內容自動暫存於瀏覽器（localStorage），重新整理後仍會保留；要長期保存請用「💾 存檔」

## 🧪 本機測試

release 前在 repo 根目錄執行 `tools/release-check.sh`（第一次會自動 `npm install` 並安裝 Playwright Chromium）。內容：載入 `index.html` 檢查無 JS 錯誤、關鍵元素與 CDN 函式庫、逐一載入範例專案，並對內嵌 JS 做 `node --check`。印出 `RELEASE CHECK: PASS` 且 exit code 為 0 才可 release。不使用 GitHub Actions。

分步版面（六個 tab）的回歸測試：在 repo 根目錄執行 `node tests/st-21-regression.mjs`（零 npm 依賴，用本機 headless Chrome）。
