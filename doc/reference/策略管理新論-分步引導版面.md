### 貫穿全程的缺口

1. 沒有 tab 式分步容器；各區塊依開發順序堆疊，不是依分析順序。
2. 沒有每步的「教材說明卡」：目前只有 `GUIDE_STEPS` 每步 1–2 句要點與 `tip`，沒有「目的／課本怎麼說／在這裡做什麼／完成檢查點／延伸頁碼」。
3. 工具內沒有連到 `manual.html` 的章節錨點（頁首頁尾只連 `manual.html`，不帶錨點；手冊已有 `#vc`、`#cells`、`#ideas`、`#premises`、`#actions`、`#control` 等錨點）。

## 三、各步教材說明卡（ST-21a 定稿後填入）

每步固定六欄：目的、課本怎麼說（短引文，最多一兩句，加引號與頁碼）、在這裡做什麼、完成檢查點、延伸閱讀頁碼、手冊錨點。ST-21a 完成後把定稿文案（與 `GUIDE_CONTENT` 常數同內容）補進此節，供日後校對。

| tab | 目的（草稿，待定稿） | 要讀的頁 |
|---|---|---|
| ① | 畫出整條產業經營流程，列出每個價值單元（活動或資產），不只列自己做的 | S 270–275 |
| ② | 逐格描述現狀；策略點依投入／產出 × 列有固定意義；「逐點描述後現狀掌握十之八九」 | S 275–281 |
| ③ | 策略要素是元件、模組是組件、策略組合是系統；用句型把因果寫清楚 | S 285–286、343–346 |
| ④ | 箭頭成立的理由就是前提，分環境／條件前提，彙整即 SWOT；疊競爭者找對陣點 | S 369–375 |
| ⑤ | 選定方案拆回策略要素，變成行動項目與權責；跨單元箭頭需跨部門協調 | S 375–377 |
| ⑥ | 行動控制與前提控制；關鍵前提要持續追蹤 | S 377–379 |

## 四、版面設計（2026-10-26 示意圖經使用者確認）

示意圖：https://claude.ai/artifact/6rJULSfnuwwj5SXigAvg7H

- **tab 列**取代 `#guideBar` 的六個節點：每格帶自己的完成度條（沿用 `guideProgress()`），下方一行整體完成度。
- **教材說明卡**在每個 tab 第一塊，可收合並記住：左欄目的＋短引文＋延伸頁碼；右欄「在這裡做什麼」＋「完成檢查點」；底部手冊錨點連結、上一步／下一步按鈕。
- **工作區**：該步區塊搬進來並預設展開。① 策略名稱與說明＋價值鏈；② 填寫進度；③ 構想分型、模組、箭頭清單、句型；④ 前提 SWOT、對陣點；⑤ 行動計畫；⑥ 控制表。
- **矩陣** ②–⑥ 常駐在工作區下方，① 隱藏。切 tab 自動切模式：② 描述策略點、③ 繪製、④–⑥ 檢視。② 的策略點面板緊貼矩陣下方。
- 頁首、sticky 專案列、頁尾不變。

## 五、實作注意事項

- 目前 tab 沿用 `guideStep`（已在 `saveState()` 存檔），不新增存檔欄位；`strategyMatrix_v4` 舊存檔照常載入，沒有 `guideStep` 時取第一個未滿 100% 的步驟（`guideCurrentKey()` 既有邏輯）。
- 不改任何資料結構 key（cellNotes、arrows、modules、premises、actionPlans 等）；PPTX 匯出與兩個 fixtures 舊存檔的輸出必須不變。
- SVG 連線（`drawLines`、`drawVcLinks`）在 `display:none` 下取不到座標：切到含矩陣或價值鏈的 tab 後要重畫；初始化若落在 ① 以外的 tab，價值鏈編輯器第一次顯示時也要重畫連線。
- 搬區塊時保留既有 id（`#premiseBox`、`#actionBox`、`#controlBox`、`#sentenceBox`、`#clashBox`、`#moduleBox`、`#arrowList`、`#cellPanel`），只改父容器；各 render 函式不動。
- `GUIDE_STEPS` 的 `anchor` 改成 tab 內容區 id；`guideGoto()` 改為切 tab 再捲動。
- 隱藏的舊「價值單元欄位管理」區（`#colEditor`）維持 `display:none`，不歸入任何 tab。
- 說明卡文字做成常數 `GUIDE_CONTENT`（同 `STRATEGY_POINT_DEFS` 的做法），每句標 `[S 頁碼]`；引文加引號。
- URL hash `#step-N` 可直連某 tab（手冊與教材可用），但 hash 不覆蓋存檔的 `guideStep` 以外的狀態。
- 窄螢幕 tab 列 3×2（沿用 ST-14d 的斷點 800px）。
- 手冊 `manual.html` 現有 26 章；ST-21f 改為依六步分章，`tools/capture-manual.mjs` 要配合 tab 切換重拍截圖。
