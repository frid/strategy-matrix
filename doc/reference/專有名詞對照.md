# 專有名詞對照：網頁用語 vs 教科書（ST-34 規劃依據）

2026-10-26 由 Explore 盤點 index.html／manual.html／README.md 與 doc/reference 摘要檔整理。頁碼 [S n] 指《策略管理新論》；摘要檔是改寫不是逐字，動手前以原書掃描頁為準。

## 一、先釐清：「策略構想」不改成「策略要素」

- 書上 Ch9 章名就是「策略矩陣分析法之應用——策略構想之描述」[S 343]；一套構想＝策略組合／策略方案 [S 365、369]。工具的〔本〕〔未〕〔競〕構想對應的是這個。
- 「策略要素」是 51 項元件 [S 285–287、338–339]，貼在箭頭上。
- 真正寫錯的是 `GUIDE_STEPS` ③ 的要點「用箭頭表達**策略要素**之間的因果」：箭頭連的是**策略點**，要素是標籤（`GUIDE_CONTENT` 的寫法是對的）。→ ST-34a 修。
- 使用者在 ST-33 原文的註解可能指的就是這句；待使用者確認。

## 四、安全性

- `cellNotes` key 用「欄名|列字母」，列字母不變 → 改 ROWS 任何 label 不影響存檔。
- `STRATEGY_KINDS`／`PREMISE_TYPES`／`VI_OPTIONS`／`UNIT_ROLES`／`CLASH_RESPONSES` 依 k／key 存檔，改 label 安全；要素存 id，改 name 安全。
- 會動到存檔的只有 #13（`SUPPORT_COLUMN_GROUP` 字串在 `COLUMN_PATHS`）與 #31（`ADV_BASES` 字串在 `cellNotes.bases`）。
- 凡「P」的改動都會讓 `tests/st-21-regression.mjs` c 區段與 v1.0.0 的逐張比對出現預期差異，需更新基準或記 decisions。
