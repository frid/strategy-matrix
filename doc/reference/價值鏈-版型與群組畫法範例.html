價值鏈版型與群組畫法

同一條示範價值鏈，主要活動含兩個群組（「生產」三項、「通路」兩項）與一個資產單元。A～E 是 Chevron 箭頭式的五種群組畫法；F～H 參考 SlideEgg 範本再加三種版型，最後一節是配色與 icon 的參考。

主要活動（葉節點） 群組範圍 支援活動 資產單元

A．大箭頭套小箭頭 nested chevron

做法
  • 群組畫成一支較高的淡色大箭頭，子單元是嵌在裡面的小箭頭。
  • 巢狀群組就再套一層，高度往外長。
取捨
  • 最直覺，「流程裡的一段子流程」一眼可辨。
  • 箭頭數多時外框很擠；群組名稱只能放大箭頭上緣。

B．葉節點一排、群組名掛上方橫帶 label band

做法
  • 所有葉節點等高等寬排成一列箭頭，與下方矩陣欄一對一。
  • 群組名稱在上方做一條橫帶，跨越它所有子單元；巢狀就多疊一層帶。
取捨
  • 與策略矩陣「群組表頭＋細項表頭」的結構完全一致，最容易對位。
  • 群組感較弱，靠橫帶與底色連成一體。

C．同色分段、箭頭互相咬合 color segments

做法
  • 一個群組用同一色相，子單元之間只用細白縫隔開；群組與群組之間才用完整的箭頭缺口。
  • 群組名稱寫在該段第一支箭頭的底部小字。
取捨
  • 視覺最乾淨，整條鏈像一支連續的箭。
  • 色相有限，群組超過四個就難分；對色弱使用者不友善。

D．兩層箭頭：群組一列、細項一列 two-tier

做法
  • 上層箭頭是「群組層級」：沒群組的單元自己佔一格。
  • 下層箭頭是葉節點，對齊在所屬群組正下方；三層巢狀就再加一列。
取捨
  • 層級最清楚，也最接近 PPTX 既有「價值鏈頁最多三層」的攤平邏輯。
  • 佔高度；沒群組的單元上下重複出現同一個名字。

E．摺疊箭頭：群組收成一支，點開才展開 collapsible

做法
  • 預設群組只畫一支箭頭，角標寫「＋3」表示內含幾項；展開時用畫法 A 或 B 在原位撐開。
  • 適合先看全貌再細看。
取捨
  • 螢幕最省，手機上尤其好用。
  • 收合時與矩陣欄對不上，需要「展開全部」才能看對應；PPTX 只能固定輸出展開狀態。

F．圓形 icon 節點＋膠囊支援列 SlideEgg 主範本

做法
  • 支援活動改成白底細框的膠囊列（不再是實色橫條）。
  • 主要活動每項一個彩色圓形 icon，名稱寫在圓下方；群組用淡色圓角底板把幾個圓框在一起，群組名寫底板上緣。
  • 右側一支黑色大 chevron 當 Margin。
取捨
  • 簡報感最強，icon 讓每個活動一眼可辨；每活動一色也方便和矩陣欄頭配色呼應。
  • icon 要有一套可挑的圖庫（或讓使用者自選 emoji）；文字在圓下方，長名稱會換行；PPTX 要畫圓＋icon＋文字三件。

G．六角鏈 SlideEgg Linear Value Chain

做法
  • 每個葉節點一顆六角形，左右相咬成一條鏈，每顆不同色相。
  • 群組用上方橫帶（同畫法 B）或同色相（同畫法 C）表示，這裡示範同色相＋橫帶並用。
取捨
  • 比 chevron 圓潤，視覺上「鏈」的意象最強。
  • 六角形內可放的文字寬度比矩形少約三成；相咬排列時欄寬與矩陣欄不等寬，對位要靠連線。

H．環狀分段 SlideEgg Industry Value Chain

做法
  • 主要活動繞成一圈弧段，順時針為流程方向，圓心放產品或 Margin；群組是相鄰弧段共用一個外環弧。
  • 支援活動放外圈或圓心旁的小列。
取捨
  • 適合封面與總覽，強調「循環」與整體。
  • 與下方矩陣欄完全對不上，連線也難畫；只建議當簡報頁或「總覽模式」，不當編輯主版型。

配色與 icon 參考

SlideEgg 三套範本的共通手法
  • 主要活動「一活動一色相」，五到六個高彩度色輪均分（藍、青、紫、橘、紅、黃），支援活動則用低彩度或白底，讓視線先落在主要活動。
  • icon 一律線條單色白色、放在實色圓裡；文字在 icon 下方或右方，不壓在色塊上。
  • Margin 用黑或深灰，與彩色活動形成對比。
套到本工具的建議
  • 現行 COLOR_PALETTES 是「整條價值鏈一色系」；可新增一套「彩虹分色」配色，每個主要活動依序取色，矩陣欄頭同色，PPTX 跟著走。
  • icon 不做圖庫，讓每個價值單元可選一個 emoji（存在 unit 新欄位 icon，舊檔無此欄位即不畫）；PPTX 直接輸出 emoji 文字。
  • 群組底色固定用該群組第一個子單元色相的 15% 透明版，避免再多一套顏色。
